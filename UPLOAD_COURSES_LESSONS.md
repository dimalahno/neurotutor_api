# Инструкция по добавлению курсов и уроков

## Общие данные
- Для загрузок курсов и уроков доступны в swagger эндпоинты в `/admin/content`
- Данные для загрузки расположены в `init_data`

## Добавление курса
1. Отправьте POST запрос на эндпоинт `/upload-courses` передава в теле файл `init_data/init_courses.json`
Ответ:
`
{
    "status": "ok",
    "count": 1,
    "courses": [
        {
            "mongo_course_id": mongo_course_id,
            "pg_course_id": course_row.id,
        }
    ],
}
`
2. В случае успеха вы получите ID созданного курса `pg_course_id`.

## Добавление урока

1. Отправьте POST запрос на эндпоинт `/upload-lessons/{course_id}` со следующими данными:
    - course_id: ID курса, к которому относится урок `pg_course_id`
    - файл `init_data/init_lessons.json`

2. При успешном добавлении вы получите:
`
{
    "status": "ok",
    "lesson_id": lesson_mongo_id,
    "course_id": course_id,
    "mongo_course_id": mongo_course_id,
}
`

## Загрузка медиафайлов для урока

1. Отправьте POST запрос на эндпоинт `/upload-media` со следующими данными:
    - lesson_id: ID урока
    - file: медиафайл (изображение, видео или аудио)
    - type: тип медиафайла

2. В случае успеха вы получите URL загруженного файла.

## Важные примечания

- Все запросы требуют авторизации с правами администратора контента
- Данные должны отправляться в формате JSON
- Размер медиафайлов не должен превышать установленные лимиты
- После создания курса и добавления уроков требуется активация курса для его публикации
